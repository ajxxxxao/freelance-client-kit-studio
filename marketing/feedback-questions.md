# Feedback Questions

Use these questions for early user interviews, Tally form updates, or direct follow-up messages.

## Product Understanding

1. What do you think Freelance Client Kit Studio helps you do?
2. Was the product purpose clear from the landing page?
3. Which part of the product felt immediately useful?
4. Which part was unclear or needed more explanation?

## Trial Intent

5. Would you be willing to try this for a real client project?
6. If not, what would stop you from trying it?
7. At what point in your client workflow would you use this?

## Feature Value

8. Which document type is most useful to you: proposal, invoice, contract terms, email, or delivery checklist?
9. Which feature feels least useful right now?
10. What document or template is missing?
11. What would make the generated documents feel more client-ready?

## Pricing and Pro Features

12. Would you consider paying $9 one-time for a Pro version?
13. If yes, what would need to be included?
14. If no, what pricing or packaging would feel more reasonable?
15. Which Pro features would matter most to you?
16. Would premium templates, polished exports, watermark removal, or brand settings make Pro more useful?

## Local-First Storage

17. How do you feel about the product being local-first?
18. Is storing data in your browser a benefit, a concern, or neutral?
19. Are you worried about losing data if browser storage is cleared?
20. Would you need backup, import, or export options before using this seriously?

## Account, Cloud, and Branding Needs

21. Do you need cloud sync for this type of tool?
22. Would you prefer an account-based version, or is no-login better for your workflow?
23. Do you need business branding settings such as logo, business name, email, payment details, or document styling?
24. Would you need multiple workspaces or client folders?

## Follow-Up

25. What is one thing you would change before recommending this to another freelancer?
26. What is one feature that would make this worth using every week?
27. Can I follow up with you after the next version?
